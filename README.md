# 🐾 PawMed 🐶

**Happy PawMed** is a full-featured **MERN stack veterinary management application** built to simplify and streamline pet care services.  
The platform allows users to manage **appointments, pet records, products, and customer interactions** efficiently, all through a **modern, responsive, and user-friendly interface**.

## ✨ Features

### 👑 Admin Roles Management
Admins have complete control over the platform. They can manage **users**, **reviews**, **products**, and **doctors** with ease.  
This feature ensures smooth system operation by allowing admins to **add, edit, update, or delete** records as needed.

### 🔐 JWT Authentication
Secure user and admin authentication using **JSON Web Tokens (JWT)**.  
This ensures that only authorized users can access protected routes and features, keeping data safe and confidential.
